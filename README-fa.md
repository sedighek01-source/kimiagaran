# ساخت APK اپ کیمیاگر

این پوشه یک پروژهٔ کامل است. اپ داخل پوشهٔ `www` است و فونت «پیدا» داخل خود اپ قرار دارد، پس بعد از نصب بدون اینترنت هم کار می‌کند. همهٔ اطلاعات فقط روی همان گوشی ذخیره می‌شود. یادآوری‌ها اعلان واقعی اندروید هستند (پلاگین LocalNotifications) و ساعت سکوت را رعایت می‌کنند.

## روش اول: بدون نصب هیچ برنامه‌ای (پیشنهادی)

گیت‌هاب APK را برایت روی سرور خودش می‌سازد.

1. در github.com یک حساب بساز و یک مخزن (Repository) جدید، مثلاً `kimiagar`، بساز.
2. محتوای همین پوشه را داخل مخزن آپلود کن (Add file ← Upload files). پوشهٔ `.github` و فایل `debug.keystore` را هم حتماً آپلود کن. اگر `.github` در فهرست فایل‌ها پنهان بود، کل پوشه را بکش و رها کن.
3. به تب Actions برو. گردش‌کار «Build APK» خودش شروع می‌شود (حدود ۵ تا ۸ دقیقه). اگر شروع نشد، آن را انتخاب کن و Run workflow را بزن.
4. وقتی سبز شد، واردش شو. پایین صفحه در بخش Artifacts فایل `kimiagar-apk` را دانلود کن.
5. فایل zip را باز کن. داخلش `kimiagar.apk` است. آن را به گوشی بفرست و نصب کن. اندروید ممکن است بخواهد «نصب از منابع ناشناس» را روشن کنی.

## روش دوم: با Android Studio روی کامپیوتر

1. Node.js و Android Studio را نصب کن.
2. فایل `debug.keystore` را در پوشهٔ `.android` در پوشهٔ کاربری‌ات کپی کن (جایگزین قبلی).
3. در پوشهٔ پروژه:

```
npm install
npx cap add android
npx capacitor-assets generate --android
npx cap sync android
npx cap open android
```

4. فایل `assets/ic_stat_kimiagar.png` را در `android/app/src/main/res/drawable/` کپی کن (آیکون اعلان).
5. در Android Studio از منوی Build گزینهٔ Build APK(s) را بزن. خروجی در `android/app/build/outputs/apk/debug` است.

## نکته‌ها

- کلید امضا (`debug.keystore`) ثابت است؛ پس هر بار که دوباره بسازی، نسخهٔ جدید روی قبلی نصب می‌شود و اطلاعات می‌ماند. این فایل را نگه دار.
- برای کافه‌بازار، مایکت یا گوگل‌پلی باید نسخهٔ release با کلید امضای اختصاصی بسازی.
- برای تغییر اپ فقط `www/index.html` را عوض کن و دوباره بساز.
- شناسهٔ اپ `com.kimiagar.app` است. نسخه‌های قبلی که با نام «اقدامات روزانه» یا «کیمیاگر» مستقیماً نصب کرده‌ای شناسهٔ دیگری دارند؛ بهتر است آن‌ها را حذف کنی.
